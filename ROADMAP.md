# Roadmap

## Phase 1 — Done (MVP)
- Shell, canvas, 19 nodes, persistence, mock AI, demo, export, branching, command palette.

## Phase 2
- Prisma SQLite, `/api/projects` CRUD, asset library (local fs).
- Prompt library, workflow templates save/load.

## Phase 3
- Local image models (ComfyUI/SD via API), vision critique, embeddings.

## Phase 4
- Brand Memory + Creative Memory (persistent decisions).
- AI Director agent that acts (create nodes, connect, generate).

## Phase 5
- Layout generation, mockup pipeline, presentation export to PDF.

## Phase 6
- Tauri desktop packaging, offline installer, auto-updater.

## Defer (out of MVP)
Auth, billing, multi-user, cloud storage — explicitly excluded per spec §40-41.
